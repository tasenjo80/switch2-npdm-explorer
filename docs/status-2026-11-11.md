# Scene status — 2026-11-11

Dated research notes from public announcements and releases through
**2026-11-11**. These are community reports and author claims, not
independently verified facts. The explorer's NPDM dataset is unchanged.

## Data freshness

- NPDM metadata remains the **2026-10-24** snapshot. No newer
  `npdm-metadata.json` appeared.
- **23.5.0** remains the current firmware. The 2026-11-10 community report
  that it patched the FS bug used by the public FS/userland paths is unchanged;
  no public 23.5.0 FS path is known.
- No new public kernel exploit, CFW, or emuNAND appeared. A Reddit post titled
  “Kernel exploit??” was labelled a joke by its author and is not evidence of
  one.

## CivSwitch on 23.5.0

- One Reddit user reports that an installed **CivSwitch** save trigger still
  starts the JavaScript loader after updating to 23.5.0. Commenters agree the
  JS/userland side still runs while the FS escalation is blocked. This is a
  single community report; CivSwitch's README still lists support only through
  23.0.1. See the
  [23.5.0 report](https://www.reddit.com/r/switch2hacks/comments/1xt235e/i_updated_my_fw_to_2350_civswitch_still_works_am/).
- CivSwitch remains **userland/JavaScript only**: no FS, native code, kernel,
  CFW, or console persistence. A working JS loader on 23.5.0 would not restore
  the FS path needed for native homebrew such as Artemis or Moonlight.
- Do not treat the report as a reason to update. Stay on 23.0.1 or lower while
  the FS-based entry points matter.

## CivSwitch variants

- [`ItsNerisma/CivSwitchLDN`](https://github.com/ItsNerisma/CivSwitchLDN) is a
  **local-wireless (LDN) transport** for CivSwitch. It requires Linux (WSL is
  not supported yet), Node.js, Python, a physical CivSwitch-compatible
  Civilization VII cartridge, and the user's own `prod.keys`. It is a delivery
  variant, not a new exploit, FS path, or CFW.
- [`MatthewKuKanich/CivSwitch-ControlCenter`](https://github.com/MatthewKuKanich/CivSwitch-ControlCenter)
  is a controller-driven interface over an existing CivSwitch Remote JS Loader.
  It provides read-only save export, save inspection, controller telemetry, and
  staged JavaScript transport. It does not install the loader or add FS access.
- [`mza1010/civswitch-kit`](https://gitee.com/mza1010/civswitch-kit) is a
  third-party Gitee package that combines CivSwitch with the existing **ns2jb**
  FS chain. Its README requires **23.0.1**, the physical Switch 1 Civilization
  VII 1.0.0 cartridge, a homebrewed Switch 1, and a Windows PC. It claims FS
  arbitrary read/write and a 90-title firmware CodeFS dump, with a roughly 30%
  per-boot success rate. The package has no release, few contributors, and is
  not independently verified here; it is a repackaging of the known 23.0.1 FS
  bug, not a new 23.5.0 path. Do not run untrusted packages.
- The `civswitch-kit` author reports a firmware dump, but no NPDM metadata from
  it is published. It could eventually produce a new dataset if the dump is
  shared and reviewed; that has not happened.

## Community claims

- The Reddit “Is this true guys?” post is a screenshot about master keys and
  emulator compatibility, not a kernel exploit. Commenters dispute parts of
  the screenshot; no new keys or dump are public.
- The 2026-11-10 DNS/IPv6 advice is operational: verify 90DNS is not being
  hijacked and disable IPv6 per network. It does not change exploit status.
- The 4/4 FS escalation reports remain unverified; no public bootstrap or
  reproducible result has appeared.

## Unchanged

- There is still **no public FS chain for 23.5.0**, kernel exploit, CFW, or
  emuNAND.
- The official WebKit port remains private/unreleased.
- The Seedsow/Artemis and Balatro saves remain save-persistent userland paths,
  not console-wide FS entry points.
- The public NPDM dataset does not include 23.5.0. No firmware, keys, saves, or
  raw research data are published here.

## Why this does not change the explorer data

No new system-module NPDM metadata appeared. CivSwitch variants are userland
tools or 23.0.1 repackaging; the claimed firmware dump is not public and has not
been reviewed. `data/npdm-metadata.json` and the service graph remain at the
2026-10-24 snapshot.
