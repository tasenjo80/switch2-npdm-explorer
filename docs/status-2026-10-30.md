# Scene status — 2026-10-30

Dated research notes from community announcements and public project releases
through **2026-10-30**. These are community reports and author claims, not
independently verified facts. The explorer's NPDM dataset is unchanged.

## Data freshness

- NPDM metadata remains the **2026-10-24** snapshot. No newer
  `npdm-metadata.json` appeared.
- **23.0.1 remained current**; no 23.0.2 was observed.

## Seedsow/Artemis entry point announced

- A community announcement on 2026-10-30 describes a **save-based entry point**
  using Artemis Engine games, especially Seedsow Lullaby. It does **not**
  require SmileBASIC.
- The announced installation route uses a **homebrewed Switch 1** with JKSV to
  restore the modified save, followed by Nintendo's official per-game save
  transfer to Switch 2. Both consoles need to be on the latest firmware for the
  transfer step. The Switch 1 is a one-time seeder.
- An alternative save-writing route is an `ns2jb` session plus
  [`ns2-savekit`](https://github.com/dougchansan/ns2-savekit), for people who
  already have the SmileBASIC route.
- A remote NSO Cloud transfer is user-reported. It requires the full game on
  the target console and an NSO membership; the demo has no cloud save.
- The announcement says the **FS sysmodule exploit is untested** but strongly
  suspected to work through this entry point. A bootstrap is still being
  created. This is not yet a public FS exploit or a general jailbreak.
- A community correction says the current path is **tethered**. The stated goal
  is the same level of access as SmileBASIC, with a future untethered launch
  from Seedsow; that goal is not yet demonstrated publicly.
- If you do not have a homebrewed Switch 1, the announcement says there is
  currently nothing you can do through this route. A later SmileBASIC write
  path may change that.

## Demo availability

- The **Japanese Seedsow Lullaby demo** was reported delisted on 2026-10-30.
  Other regions may follow. Keep the demo if you already have it.
- The demo is the preparation step, not a complete exploit. Do not update the
  console while preparing unless the project guidance says to.

## Tooling

- [`purple442/seedsow-lua-editor-pro`](https://github.com/purple442/seedsow-lua-editor-pro)
  v0.2.0 is a public JKSV-ready Slot 4 editor and research suite built on the
  Seedsow Lua Editor. It is not the exploit itself.
- A community report describes reading SD-card files through the privileged
  filesystem proxy (`OpenSdCardFileSystem`). Write access was not confirmed.
- The seedsow Lua Editor v0.1.3 remains the reference editor release:
  <https://github.com/DialingSpoon527/seedsow-lua-editor/releases/tag/v0.1.3>.

## WebKit and kernel status

- The official WebKit port remains **private/unreleased**. Reports that it may
  not be released are unverified.
- There is still **no public kernel exploit, CFW, or emuNAND**.
- The new Seedsow entry point is userland/save-level until an FS escalation is
  actually shown to work.

## Why this does not change the explorer data

No new system-module NPDM metadata appeared. Save entry points, editor forks,
and launcher work do not provide system NPDM metadata.
`data/npdm-metadata.json` and the service graph remain at the 2026-10-24
snapshot.
