## CivSwitch public release

- [`Gezine/CivSwitch`](https://github.com/Gezine/CivSwitch) is a public,
  MIT-licensed XSS toolchain for the **Switch 1 edition of Civilization 7**.
  Release `1.0` (2026-11-01) provides Pico firmware for RP2040/RP2350 and an
  installer that writes a save-persistent trigger into the game's savedata.
- The README says only the **physical 1.0.0** cartridge is supported; digital,
  updated, reprint, and MIG/flashcart copies are not documented. It recommends
  a **Pico 2 (RP2350)**; Pico 1 is untested by the author.
- The author reports testing on Switch 1 22.5.0 and Switch 2 20.4.0 and 23.0.1.
  This has not been independently verified here.
- It is **userland/JavaScript only**. It brings up a remote JS loader on TCP
  `:9026` and can run JavaScript payloads; it is not FS, native code, kernel,
  CFW, or console persistence. The trigger lives inside the game save.
- The project does not provide an FS escalation or a port of the
  Seedsow/Artemis chain. If you already have SmileBASIC/`ns2jb` or a working
  Seedsow entry, CivSwitch adds no FS capability.
- Community reports on 2026-11-02 treated it as a userland entry point, not an
  FS path. Claims of FS access or a full jailbreak remain unverified.

## Seedsow/Artemis

- The Seedsow/Artemis path remains **tethered**; the FS escalation is
  **unconfirmed** and not public. Community reports describe continued FS
  research, but no reproducible public chain or bootstrap exists.
- The Japanese Seedsow Lullaby demo was delisted on 2026-10-30. A Korean demo
  takedown was reported on 2026-11-02; it has not been independently confirmed.
  Keep existing installs.
- Seedsow Lua Editor v0.1.3 remains the reference editor while it targets
  23.0.1 on both consoles.

## WebKit payload pack and firmware

- On 2026-11-02 the public
  [`Jmesmykil/switch2-captive-portal-research`](https://github.com/Jmesmykil/switch2-captive-portal-research)
  repo was replaced with a payload pack containing CSSFontFace UAF/ARW/JOP
  files and a launcher.
- The repo's README calls the release a **reachability/diagnostic payload** and
  says it does not provide code execution. The commit message claims a
  **weaponized chain**. Those claims conflict, and neither has been independently
  verified here. The pack does not establish FS, kernel, or 23.0.1 support.
- The old CVE-2026-43715 trigger page was removed; links to it may no longer
  resolve.
- The free-game **Drift Legends 2** "entry" was reported fake and is not an
  entry point.
- There is still **no public kernel exploit, CFW, or emuNAND**.

## Why this does not change the explorer data

No new system-module NPDM metadata appeared. CivSwitch is a game-side userland
path and does not supply system NPDM metadata. `data/npdm-metadata.json` and
the service graph remain at the 2026-10-24 snapshot.
