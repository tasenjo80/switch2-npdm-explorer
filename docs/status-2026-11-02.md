## CivSwitch public release

- [`Gezine/CivSwitch`](https://github.com/Gezine/CivSwitch) is a public,
  MIT-licensed XSS toolchain for the **Switch 1 edition of Civilization 7**.
  Release `1.0` (2026-11-01) provides Pico firmware for RP2040/RP2350 and an
  installer that writes a save-persistent trigger into the game's savedata.
- The README says only the **physical 1.0.0** cartridge is supported; digital,
  updated, reprint, and MIG/flashcart copies are not documented. It recommends
  a **Pico 2 (RP2350)**; Pico 1 is untested by the author.
- The author reports testing on Switch 1 22.5.0 and Switch 2 20.4.0 and 23.0.1.
  This has not been independently verified here.
- It is **userland/JavaScript only**. It brings up a remote JS loader on TCP
  `:9026` and can run JavaScript payloads; it is not FS, native code, kernel,
  CFW, or console persistence. The trigger lives inside the game save.
- The project does not provide an FS escalation or a port of the
  Seedsow/Artemis chain. If you already have SmileBASIC/`ns2jb` or a working
  Seedsow entry, CivSwitch adds no FS capability.
- Gezine stated on 2026-11-02 that the fs bug "does work at CivSwitch" but
  still needs porting. This is an author claim, not an independently verified
  result; no public port exists, and CivSwitch remains userland/JS only.
- Community reports on 2026-11-02 treated it as a userland entry point, not an
  FS path. Claims of FS access or a full jailbreak remain unverified.

## Seedsow/Artemis

- The Seedsow/Artemis path remains **semi-tethered**; the FS escalation is
  **unconfirmed** and not public. Community reports describe continued FS
  research, but no reproducible public chain or FS bootstrap exists.
- On 2026-11-02 Alula published
  [`alula/switch-artemis-launcher`](https://github.com/alula/switch-artemis-launcher)
  v1, a public save-based launcher for the **Nora 2 demo** and **Seedsow
  demo**. It provides on-device Lua/native userland execution, an HTTP
  eval/save API, and fail-safe updates.
- The launcher is **not an entry point**: it needs a launcher save installed
  through a homebrewed Switch 1/JKSV and official transfer, or `ns2jb` RPC
  (not yet tested by the author). It supports demos only and does not provide
  FS or kernel access. If a future firmware closes the 23.0.1 window, another
  FS exploit is still needed to install the save.
- The Japanese Seedsow Lullaby demo was delisted on 2026-10-30. A Korean demo
  takedown was reported on 2026-11-02; it has not been independently confirmed.
  Keep existing installs.
- Seedsow Lua Editor v0.1.3 remains the reference editor while it targets
  23.0.1 on both consoles.

## Tooling

- `mac2jb` v0.7.1 (2026-11-02) is an Apple Silicon macOS helper for `ns2jb`
  and CivSwitch. It adds CivSwitch typing/loader setup, a CivSwitch Control
  Center for read-only save exports/controller monitoring/JavaScript staging,
  Artemis launcher save installation with backups, SaveKit, native
  HBLauncher/MintNES, OunceCake WebDAV, and browser research scripts.
- It remains a helper, not an exploit or CFW. The CivSwitch flow does not expose
  `ns2jb`'s held RPC, and the Artemis RPC install path is still untested.
  Requirements include macOS 14+, an unsigned USB driver, and reduced
  security/SIP changes.
- `ns2-savekit` added an **Artemis HTTP transport** on 2026-11-02: save access
  through the Artemis launcher's unauthenticated port 8080 server without an
  `ns2jb` session. Hardware-tested reads/writes and explicit-file backups; it
  is LAN-only, limited to the launcher's own save, and does not provide a
  complete restore or FS access.
