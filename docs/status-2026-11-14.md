# Scene status — 2026-11-14

Dated research notes from public announcements and releases through
**2026-11-14**. These are community reports and author claims, not
independently verified facts. The explorer's NPDM dataset is unchanged.

## kaiHEN

- [`ouncebrew/kaihen`](https://github.com/ouncebrew/kaihen) is a public
  **homebrew enabler and minimal CFW** for Switch 2. Its latest release is
  **20261114d**. It provides an `ldr:ro` replacement, HEN service, native
  homebrew menu (`hbmenu`), a libnx-compatible devkit (`libounce`), an
  EGL/OpenGL/Vulkan driver (`OunceVK`), JIT support, and OunceShell with FTP.
- It is **not a kernel exploit or a full CFW**. It grants the access available
  to the `fs` system modules, including system NAND. There is no kernel,
  emuNAND, cold boot, or persistent boot chain. HEN lasts until the console
  restarts; the acquisition step must be repeated.
- It requires **23.0.1** and an SD card. It is launched from a supported
  acquisition tool, then a **native Switch 2 game** must be opened while
  holding R. The first launch records the game's signing policy; the next
  R-held launch opens hbmenu. Switch 2 Editions and Switch 1 games are not a
  substitute. A Switch 2 game cartridge or an already-installed native digital
  title is required.
- **Brick risk is real:** the README warns that malicious homebrew can write to
  system NAND and permanently break the console. This is experimental software,
  not a consumer jailbreak.
- Native homebrew is working: testers report full-speed native mGBA on
  Pokemon Emerald with sound, saves, and save states. Existing Switch 1
  homebrew using libnx and OpenGL/Vulkan can be compiled for Switch 2 with the
  devkit, but a native Moonlight release is not yet public.
- Launch routes:
  - `ns2jb` with SmileBASIC, or
  - [`s8n/civ7-fs-kaihen`](https://github.com/s8n/civ7-fs-kaihen), which boots
    kaiHEN through CivSwitch and the Civ7 FS port. It needs the physical Civ 7
    1.0.0 cartridge, a working CivSwitch save trigger, an SD card, and a PC on
    the same LAN. It is 23.0.1-only and experimental.
  - The Seedsow/Artemis save path is not a kaiHEN launcher.

## Moonlight and CivHomebrew

- Moonlight remains a **CivHomebrew userland app** inside Civ 7. kaiHEN makes
  native homebrew possible, but there is no public native Moonlight `.nro` or
  standalone Moonlight app yet.
- CivHomebrew **v1.3.6** was published on 2026-11-13. Moonlight's latest public
  release remains **v0.1.3**. The 23.5.0 path is still untested.
- The userland Moonlight route still needs the physical Civ 7 1.0.0 cartridge
  and CivSwitch; the Seedsow demo alone is not enough.

## Supernag and FS ports

- The 23.0.1 forced-update/supernag report remains unchanged. No Seedsow
  reports have appeared. Stay offline/90DNS; do not test it online. A YouTube
  “supernag bypass” claim is unverified and is not a public method.
- CivSwitch FS ports remain **23.0.1-only** and experimental. `civ7-fs` now has
  retry/backoff improvements, but public results are still mixed. `civ7-fs` +
  kaiHEN is a real native-homebrew route; it is not a 23.5.0 path.
- Alula still warns against current Artemis-game FS implementations because
  corrupting the save or game can lose the entry point.

## Unchanged

- NPDM metadata remains the **2026-10-24** snapshot. No newer
  `npdm-metadata.json` appeared.
- There is still **no public kernel exploit, full CFW, or emuNAND**. kaiHEN is
  a tethered fs-level HEN/minimal CFW, not a kernel exploit.
- The official WebKit port remains private/unreleased.
- The public NPDM dataset does not include 23.5.0. No firmware, keys, saves, or
  raw research data are published here.

## Why this does not change the explorer data

No new system-module NPDM metadata appeared. kaiHEN is a homebrew runtime; its
NAND access and native-homebrew support do not provide a reviewed firmware or
NPDM dataset. The explorer remains at the 2026-10-24 snapshot.
