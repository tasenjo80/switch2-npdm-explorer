## Ozone and libnx-ounce

- [`alula/Ozone`](https://github.com/alula/Ozone) is an experimental,
  source-only port of selected Atmosphere components to the Switch 2 “Ounce”
  target. It includes work on `ro`, `fs`, `kern`, and platform-aware program
  IDs.
- The project's README explicitly says it is **not a full CFW and very likely
  will never be one**. It is intended to make Atmosphere replacement modules
  and libraries buildable for eventual homebrew development. There is no
  release, installer, bootloader/kernel bypass, or persistence.
- [`alula/libnx-ounce`](https://github.com/alula/libnx-ounce) is a Switch 2
  libnx fork for building native homebrew. It is a development library, not a
  runtime or entry point.
