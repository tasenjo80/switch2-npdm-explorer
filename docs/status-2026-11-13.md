# Scene status — 2026-11-13

Dated research notes from public announcements and releases through
**2026-11-13**. These are community reports and author claims, not
independently verified facts. The explorer's NPDM dataset is unchanged.

## Moonlight and CivHomebrew

- [`XITRIX/Moonlight-CivSwitch`](https://github.com/XITRIX/Moonlight-CivSwitch)
  **v0.1.3** is a public Moonlight client for the Switch 2, running inside
  **CivSwitch** through CivHomebrew. It supports Sunshine pairing, a game
  library, controller/touch/keyboard input, H.264 video, and stereo audio. The
  README reports short 1080p60 streams on a Switch 2; it is **not** a sustained
  60 FPS qualification.
- It requires the physical Switch 1 edition of Civilization VII at **1.0.0**,
  a working CivSwitch loader, CivHomebrew, and Sunshine on a PC on the same
  network. It is a userland `.civapp` inside the Civ 7 process: no FS, kernel,
  CFW, native OS, or standalone homebrew environment.
- [`XITRIX/CivHomebrew`](https://github.com/XITRIX/CivHomebrew) is a CivSwitch
  JavaScript app launcher. It installs `.civapp` packages over FTP, keeps them
  in save data, and launches Moonlight, SW2NES, and Jellyfin. It does not support
  `.nro`, FS, or native homebrew.
- [`mac2jb`](https://github.com/cpypwn/mac2jb) **v0.8.2** adds CivHomebrew app
  browsing/installation for Moonlight, SW2NES, and Jellyfin. It also documents a
  CivSwitch FS path that has reached 4/4 verification on a Switch and opens held
  RPC for SaveKit, OunceCake, and modloader; that is an author claim, not
  independently verified here.
- CivSwitch's JavaScript loader is user-reported to still run on **23.5.0**.
  CivHomebrew/Moonlight may therefore be possible there, but no public 23.5.0
  test exists. FS-dependent tools remain blocked on 23.5.0. Do not update solely
  on the possibility.

## CivSwitch FS ports

- [`HerXayah/civ7-fs`](https://github.com/HerXayah/civ7-fs) is a public,
  **23.0.1-only** CivSwitch FS port built on the `civswitch-kit` work. It claims
  a higher success rate, but public comments report repeated failures at the
  2/4 stage; treat it as unstable.
- The Gitee [`civswitch-kit`](https://gitee.com/mza1010/civswitch-kit) package
  remains a 23.0.1-only repackaging of the known FS bug. It claims FS read/write
  and a firmware dump; neither is independently verified here.
- [`BlafKing/OunceCake-Civ7`](https://github.com/BlafKing/OunceCake-Civ7) adapts
  OunceCake to dump a user's own game content through the CivSwitch FS path. It
  supplies no keys, does not dump system NPDM metadata, and is not a 23.5.0
  path. Keep any dumps private.
- **Alula warns against current Artemis-game FS implementations:** corrupting
  the save or game can lose the entry point. A safer implementation is in
  progress. See the
  [warning](https://x.com/__alula/status/2120954659485475243). Do not use the current Seedsow/Artemis FS experiments; the Artemis
  launcher itself remains a separate userland path.

## 23.0.1 supernag

- The 2026-11-12 community report remains unchanged: multiple users on 23.0.1
  are forced to update before SmileBASIC or Civ 7 will launch, and Maintenance
  Mode does not clear it. No Seedsow reports had appeared.
- Stay offline and/or keep 90DNS active; disable IPv6 per network. A user report
  says even router blocking did not prevent the block after one failed attempt;
  do not go online to test it.

## Unchanged

- NPDM metadata remains the **2026-10-24** snapshot. No newer
  `npdm-metadata.json` appeared, including from the `civswitch-kit` dump claim.
- There is still **no public 23.5.0 FS path**, public kernel exploit, CFW, or
  emuNAND. Public 23.0.1 CivSwitch FS ports exist but are unstable.
- The official WebKit port remains private/unreleased.
- Moonlight here is a CivHomebrew app inside Civ 7, not a native OS or a
  replacement for the missing FS/CFW stack.
- The Seedsow/Artemis and Balatro saves remain save-persistent userland paths.

## Why this does not change the explorer data

No new system-module NPDM metadata appeared. Moonlight/CivHomebrew are userland
apps; the CivSwitch FS ports only exercise the existing 23.0.1 FS bug. The
`civswitch-kit` dump claim has not produced a public NPDM dataset. The explorer
remains at the 2026-10-24 snapshot.
