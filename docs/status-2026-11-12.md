# Scene status — 2026-11-12

Dated research notes from public announcements and releases through
**2026-11-12**. These are community reports and author claims, not
independently verified facts. The explorer's NPDM dataset is unchanged.

## 23.0.1 forced-update reports

- Community staff announced on 2026-11-12 that multiple users on **23.0.1**
  are receiving a forced-update/supernag when launching **SmileBASIC 4** or
  **Civilization VII**. They report Nintendo is blocking the titles until the
  console updates to **23.5.0**, and that Maintenance Mode does not clear it.
  No Seedsow Lullaby reports had appeared at review time. This is a community
  report, not independently verified here, but it is high-impact if accurate.
  See the
  [Reddit mirror](https://www.reddit.com/r/switch2hacks/comments/1xu2zdc/nintendo_is_blocking_people_from_using_smilebasic/).
- **Stay offline and/or keep 90DNS active; disable IPv6 per network.** Do not
  go online to test the supernag. The announcement's guidance is to avoid
  getting flagged in the first place.
- If the report holds, the **SmileBASIC/ns2jb** and **CivSwitch** launch paths
  on 23.0.1 can be blocked online even before the console is updated. The
  Seedsow/Artemis save path has no reported supernag yet, but keep it offline.
- This does not create a 23.5.0 FS path. The 2026-11-10 report that 23.5.0
  patched the FS bug is unchanged, and no public replacement is known.

## CivSwitch after the update

- One Reddit user reports an installed CivSwitch save trigger still starts its
  JavaScript loader after updating to 23.5.0; the FS escalation remains
  blocked. That remains a single unverified report.
- If the 23.0.1 supernag reports are accurate, the practical CivSwitch picture
  is squeezed from both sides: launching Civ 7 on 23.0.1 may require an update,
  while 23.5.0 still has no public FS path. CivSwitch remains userland/JS only
  and is not a route to native homebrew or Moonlight.
- The `civswitch-kit` Gitee package remains a 23.0.1-only repackaging of the
  existing ns2jb FS chain. It does not bypass the supernag or the 23.5.0 patch.

## mac2jb v0.8.1

- [`mac2jb`](https://github.com/cpypwn/mac2jb) **v0.8.1** was released on
  2026-11-11 for Apple Silicon macOS. It adds one-click installation of
  `ns2jb-modloader` using compatible mods already on the Switch SD card; the
  Mac-folder mod upload remains an optional secondary action.
- It is a macOS helper, not an exploit or CFW. It does not add FS permissions,
  bypass the 23.0.1 supernag, or provide a 23.5.0 exploit.

## CivHomebrew userland

- [`Rodpad/SW2NES`](https://github.com/Rodpad/SW2NES) is a public NES emulator
  packaged as a `.civapp` for CivHomebrew. It demonstrates userland apps inside
  the Civ 7 process; it is not a console entry point or FS path.
- A community Jellyfin UI proof of concept using CivHomebrew and Moonlight
  source was posted but is unreleased, AI-assisted, and not available as a
  repository or release. Treat it as a demo, not a usable streaming client.
- These apps do not change the FS, kernel, CFW, or NPDM-data status.

## Unchanged

- NPDM metadata remains the **2026-10-24** snapshot. No newer
  `npdm-metadata.json` appeared.
- There is still **no public FS chain for 23.5.0**, public kernel exploit, CFW,
  or emuNAND.
- The official WebKit port remains private/unreleased.
- The Seedsow/Artemis and Balatro saves remain save-persistent userland paths,
  not console-wide FS entry points. No NPDM metadata from the `civswitch-kit`
  firmware-dump claim is public.

## Why this does not change the explorer data

No new system-module NPDM metadata appeared. The supernag report affects whether
existing entries can launch; it does not add or replace NPDM metadata. The
`mac2jb` and CivHomebrew updates are tools and userland apps. The explorer
remains at the 2026-10-24 snapshot.
