# Scene status — 2026-10-29

Dated research notes from community channels and public project releases
through **2026-10-29**. These are community reports and author claims, not
independently verified facts. The explorer's NPDM dataset is unchanged.

## Data freshness

- NPDM metadata remains the **2026-10-24** snapshot. No newer
  `npdm-metadata.json` appeared in this window.
- **23.0.1 remained current**; no 23.0.2 was observed.
- SmileBASIC 4.4.9 was delisted from the eShop on **2026-10-22**. Existing
  owners are the practical audience for the full-game route.

## SmileBASIC demo support

- The upstream ns2jb package targets **SmileBASIC 4.4.9**. The community fork
  [`BermTheSequel/ns2jb2`](https://gitlab.com/BermTheSequel/ns2jb2) advertises
  support for the **4.4.6 demo** in addition to the full game.
- The fork asks for Ethernet on both the computer and console, the game on
  internal storage, and warns that the FS exploit is still unstable; its README
  estimates a best-case **20% success rate**.
- The demo cannot save programs. The fork documents `SAVEV "TXT:NS2"` and
  `LOADV` workarounds so the bootstrap can be re-entered without retyping it.
- Multiple users report reaching **4/4** and dumping games with the demo.
  Others still hit insufficient-save-space errors, freezes, or failed
  acquisition. Treat demo support as real but less reliable than the full
  game.
- This is still a **SmileBASIC** route. It does not create a no-SmileBASIC
  entry point.

## Seedsow and Artemis save path

- [Seedsow Lua Editor v0.1.3](https://github.com/DialingSpoon527/seedsow-lua-editor/releases/tag/v0.1.3)
  (2026-10-28) ships a ready-built save and keeps the **23.0.1 on both
  consoles** preparation checkpoint while that firmware is current.
- [`dougchansan/ns2-savekit`](https://github.com/dougchansan/ns2-savekit) (MIT)
  reports hardware-tested save read/write through a live ns2jb session. Its
  author reports installing the Seedsow Lua Editor save with **no JKSV, no
  Switch 1, and no Nintendo save transfer**. Community results are mixed.
- The same project reports running arbitrary Lua inside a shipping Artemis
  game from save data, with `io`, `os`, `debug`, and `package` available. This
  is a game-level Lua foothold, not a confirmed native or console-level escape.
- The actual console-level Artemis entry point is still **not public**. The
  editor and save tooling are preparation, not a general jailbreak.

## Tooling

- [`ariankordi/OunceCake`](https://github.com/ariankordi/OunceCake) is a
  community fork that serves title contents over HTTP/WebDAV and reports
  dumping full system firmware titles (RomFS/ExeFS) and system data archives.
  That could produce future NPDM metadata, but no new dataset is included
  here.
- [`CriticalThinkingHorizon/SpecialOctoLauncher`](https://github.com/CriticalThinkingHorizon/SpecialOctoLauncher)
  is a public SmileBASIC/SPIR-V launcher. Its author claims a 100% success
  rate for launching; this has not been independently verified here.
- [`wowilookgood/ns2-flipper-typer`](https://github.com/wowilookgood/ns2-flipper-typer)
  is a typing/bootstrap helper for the Flipper WiFi Devboard.
- These are convenience and research tools, not CFW or a kernel exploit.

## WebKit and kernel status

- The official WebKit port remains **private/unreleased**.
- One researcher reported a WebKit `CSSFontFace` use-after-free candidate with
  arbitrary read and `addrof`, and said a write primitive was in progress.
  This is unverified and not a public exploit.
- There is still **no public kernel exploit, CFW, or emuNAND**.

## Bans and telemetry

- No confirmed bans were reported in this window.
- One tester reported no ban after roughly 48 hours of telemetry while running
  the non-FS, SmileBASIC-sandboxed GPUBrewLauncher. This is a single anecdote,
  not a safety guarantee.
- Reconnecting after dumping or save editing still carries unknown risk.

## Why this does not change the explorer data

No new system-module NPDM metadata was published. The HTTP OunceCake fork can
dump system-title ExeFS, which could provide metadata later, but no new dataset
exists yet. Game dumps, save tooling, demo support, and launcher work alone do
not add metadata. `data/npdm-metadata.json` and the service graph remain at the
2026-10-24 snapshot.
