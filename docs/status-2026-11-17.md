# Scene status — 2026-11-17

Dated research notes from public announcements and releases through
**2026-11-17**. These are community reports and author claims, not
independently verified facts. The explorer's NPDM dataset is unchanged.

## Seedsow FS and kaiHEN

- [`Malev0/seedsow-fs-kaihen`](https://github.com/Malev0/seedsow-fs-kaihen) is a
  public, PC-driven **23.0.1-only** port of the fs exploit to Seedsow Lullaby.
  It runs kaiHEN from a Seedsow demo/full save and then uses the usual hold-R
  homebrew launch.
- It requires Seedsow Lullaby installed **with alula's launcher save**, an SD
  card, a PC with Node.js 20+, and a controller bridge for the console prompts.
  It also requires a native Switch 2 game for the final hbmenu launch. The
  Seedsow demo alone is not enough; users without the launcher save still need
  a prior entry or a save transfer.
- It is a race, not a deterministic exploit. Failed runs can wedge the app, and
  the README recommends restarting the app or console after repeated failures.
  No 23.5.0 support is claimed. **Alula's warning against current Artemis FS
  implementations still applies:** a corrupt save or game can lose the entry
  point.
- [`kaiHEN`](https://github.com/ouncebrew/kaihen) **20261117.1** is current. It
  adds packaged `libkaihen` for the devkit and a devkit package repository; the
  runtime remains a tethered fs-level HEN/minimal CFW, not a kernel exploit or
  full CFW. Native homebrew now includes mGBA, Sphaira, and KaiPlayer, but there
  is still no native Moonlight release.
- [`s8n/civ7-fs-kaihen`](https://github.com/s8n/civ7-fs-kaihen) and
  [`yyoossk/kaihen-installer`](https://github.com/yyoossk/kaihen-installer)
  remain the Civ 7 launch routes. The latter is an installer convenience, not a
  new entry point.

## Moonlight and CivHomebrew

- Moonlight for CivSwitch is now **v0.1.4**; CivHomebrew is **v1.3.8**. Both
  remain userland apps inside Civ 7. The native renderer updates do not create a
  native OS, FS, kernel, or CFW path, and 23.5.0 is still untested.
- The CivHomebrew Moonlight route still needs the physical Civ 7 1.0.0
  cartridge and CivSwitch. The Seedsow FS route can boot kaiHEN without Civ 7,
  but it does not itself provide a Moonlight app.

## 23.0.1 supernag

- The forced-update/supernag reports continue. No Seedsow reports had appeared;
  users who accidentally go online are still losing the Civ 7 launch path.
  Stay offline/90DNS, disable IPv6, and do not test it online.
- No public supernag bypass is confirmed. A YouTube claim remains unverified.

## Unchanged

- NPDM metadata remains the **2026-10-24** snapshot. No newer
  `npdm-metadata.json` appeared.
- There is still **no public kernel exploit, full CFW, or emuNAND**. kaiHEN is a
  tethered fs-level HEN/minimal CFW.
- The official WebKit port remains private/unreleased.
- The public NPDM dataset does not include 23.5.0. No firmware, keys, saves, or
  raw research data are published here.

## Why this does not change the explorer data

No new system-module NPDM metadata appeared. Seedsow FS is another acquisition
route to the existing fs access, and kaiHEN is a homebrew runtime; neither
supplies reviewed firmware or NPDM metadata. The explorer remains at the
2026-10-24 snapshot.
