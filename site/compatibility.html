How to read this page

Each claim is labelled by source. Volatile step-by-step guidance stays in the latest dated status note; this page tracks capabilities, not instructions.

Public Announced Private Community report No public path Not re-tested

Public means a source or binary is publicly available. Announced means a public community announcement describes the path, but the bootstrap or release is not public yet. Private means work exists but is not released. Community report means public channels reported it; it is not independently verified here. No public path means no public method is known. Not re-tested means upstream documentation was used but the tool was not re-run for this page.

SmileBASIC 4.4.9 was delisted from the eShop on 2026-10-22 (store page), so ns2jb is not a practical entry point for new users without an existing copy.

Demo support is community-reported through ns2jb2. The full 4.4.9 route remains the reference; the demo cannot save programs and is less reliable.

Seedsow entry-point update (2026-10-30): a save-based entry point has been announced. The FS escalation is untested and the bootstrap is not public; do not treat this as a working jailbreak yet.

The Japanese Seedsow demo was delisted on 2026-10-30. Other regions may follow; keep the demo if you already have it.

ns2-savekit installs the Seedsow editor save through an ns2jb session. It is an alternative to the Switch 1/JKSV transfer, not a no-SmileBASIC path for that route.

The HTTP OunceCake fork reports dumping system firmware titles and system data archives. That could produce future NPDM metadata, but no new dataset is included here.

Seedsow preparation checkpoint: the editor project targets 23.0.1 on both consoles while it is current. If a newer firmware appears, stop before updating and check the project guidance.

Known hazards

  • There is no public kernel exploit, CFW, or emuNAND.
  • Community reports attribute at least two bricks to save-data/NAND experiments, not to ordinary dump runs. Do not write to NAND; treat save and NAND experiments as dangerous.
  • ns2jb heap grooming has been reported to overwrite more than the intended FS process permissions; one tester reported losing a SmileBASIC save.
  • No confirmed bans were reported in these windows, but bans can be delayed. Staying offline while jailbroken is the cautious choice.
  • Community staff reported no confirmed Switch 2 emulators or recomps. Files or links claiming otherwise may be malware and should not be trusted or redistributed.
