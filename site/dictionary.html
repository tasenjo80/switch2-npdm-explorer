Overview

NPDM is the metadata header of a Switch executable. This project stores a small, normalized subset of that metadata for installed full SystemProgram titles. It does not include NPDM binaries, NCAs, keys, saves, or game content.

  • Metadata only. Field presence does not establish a vulnerability or an exploit path.
  • One snapshot. The dataset is a single community dump; fields can be incomplete or mislabeled.
  • Not decoded. Raw bitmasks, syscall numbers, and handle-table values are recorded, not interpreted.
  • Scope. Installed full SystemProgram titles only; SystemDataArchive titles are excluded.

Module fields

Top-level fields on each module entry.
Field Type Meaning Notes
file string Source path recorded for the module in the community dump. Metadata only; no file is included or downloadable here.
name string Module display name, such as chat or fsp-srv. Used for display and sorting.
programId string 16-character lowercase hexadecimal program ID. Primary module key in the explorer.
is64Bit boolean Whether the module is recorded as a 64-bit image. Raw NPDM field.
addressSpace integer Recorded address-space value. Not decoded into an address range by this project.
mainThreadPriority integer Main-thread priority value. Raw NPDM field.
mainThreadCore integer Main-thread core affinity value. Raw NPDM field.
mainThreadStackSize integer Main-thread stack size in bytes. Raw NPDM field.
systemResourceSize integer Recorded system-resource size. Raw NPDM field; meaning depends on the system version.
version integer Raw version value. The viewer also exposes a hexadecimal convenience value.
productCode string Recorded product code, when present. Often empty for system modules.
hostsServices string[] Exact service names this module provides. Drives the service graph's host edges.
usesServices string[] Exact service names this module consumes. Drives the service graph's user edges.
acidHostsServices string[] Services recorded through the ACID host list. Preserved separately; not currently used by the focus graph.
kernel object Kernel metadata block. See Kernel fields.

The viewer adds convenience fields such as versionHex, counts, and surface. Those are documented under Derived values.

FS permissions

Filesystem permission fields.
Field Meaning How the viewer uses it
fsPermissions A 16-hex-digit filesystem permission mask from the NPDM. Displayed as a compact mask. The viewer does not decode individual bits.
fsPermissionsHex The same value with a 0x prefix. Convenience display only.
fsPermNonzero Whether the permission mask is nonzero. Used as a filter and as a surface-score bonus. It is not a claim about which mounts or operations are allowed.

Treat the mask as a research lead. The dataset does not include the bit-level FS permission table or the service ACLs needed to interpret each bit.

Kernel fields

Fields under each module's kernel object.
Field Type Meaning Notes
syscalls integer[] Syscall numbers recorded for the module. Numbers only; this dataset does not include syscall names or signatures.
maps integer Count of recorded memory-map entries. The entries themselves are not included.
irqs integer[] IRQ numbers recorded for the module. Raw values; no interrupt-controller mapping is provided.
appletType integer or null Recorded applet type value. The enum mapping is not decoded here.
handleTable integer or null Recorded handle-table size/value. Not a list of handles; meaning is not decoded here.
debug object or null Raw debug metadata block. The viewer uses presence as a filter, not as a vulnerability signal.

Service graph

The graph is assembled from the exact service names listed by each module. Names are not case-folded and are not merged; ldr:ro and ldr:cmpt are separate services. Families are a display grouping only.

Service, family, and derived graph fields.
Field Meaning Notes
hostsServices / hosted by A module provides a service; the service lists that module as a host. The focus graph's left side for a module or the host side for a service.
usesServices / used by A module consumes a service; the service lists that module as a user. The focus graph's other side.
acidHosts Modules recorded through acidHostsServices. Preserved in the service entry; not used by the focus graph or path finder.
name Exact service name. Primary service key.
family Text before the first colon, or the whole name when there is no colon. Example: spl:mig belongs to family spl; fsp-srv is its own family.
hostCount / useCount Number of distinct modules that host or use the service. Counts are based on the exact names in the dump.
noHost True when a service has users but no recorded host. Usually a built-in sysmodule/KIP or a provider missing from the dump; not a confirmed classification.
key Curated high-interest service marker. A research priority, not a vulnerability rating.
likelyBuiltin Family-level heuristic for families whose services all lack hosts and match a known built-in set. Heuristic only.

Derived values

Values computed by the build or viewer, not raw NPDM fields.
Value Definition Use
hostCount, useCount Length of the module's hosted or used service lists. Sorting, summaries, and surface scoring.
syscallCount, mapCount, irqCount Counts derived from the corresponding kernel fields. Table columns and surface scoring.
surfaceRaw 3 × hosts + uses + 0.5 × syscalls + 0.5 × maps + 0.5 × min(irqs, 10) + 5 if FS permissions + 5 if debug. Research-attention heuristic.
surface surfaceRaw normalized to 0–100 across this dataset. Sorting and comparison; not an exploitability score.
focus Curated research-priority flag from the source discussion. Highlighting and filtering; not a vulnerability claim.
tags Descriptive labels such as filesystem, network, GPU, or input. Filtering and grouping.
note, noteSource Short research note and its source label. Context only; verify before relying on it.

Limits and provenance

  • Single community snapshot: 2026-10-24, reviewed 2026-10-27. No newer NPDM metadata is included.
  • Installed full SystemProgram titles only. SystemDataArchive titles such as BrowserCoreDll (0x85D) are out of scope.
  • No NPDM binaries, NCAs, service ACLs, memory descriptors, keys, saves, or game data.
  • The service graph is derived from names in the dump. It is not a runtime IPC trace.
  • See DATA-PROVENANCE.md and methodology.md.
